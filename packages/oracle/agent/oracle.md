# Oracle package playbook

Treat `src/` as framework-neutral protocol and evidence code. Never import React, Solid,
compiler/IR, Vite, filesystem, gate, or dossier types there. Framework implementations belong
to target packages; the handwritten React/Solid code under `test/fixtures/` exists only to
calibrate the oracle itself.

Preserve the phase order and await `Adapter.dispatch` before the `action:n:after` observation.
Normalization changes, scenario edits, mutant edits, or receipt-state changes alter product
evidence and require a full Chromium recalibration. A mutant that stops being rejected is a
finding and stop condition, not a test to weaken.

Never write a passing receipt without executing the comparisons that produced it. Preserve
`blocked-by-upstream` records and their finding ids explicitly.
