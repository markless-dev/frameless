output-switcher

One source on the left, its real emitted output on the right. Superseded by framework-carousel, which is the same argument with the avara selection mechanic — reach for that one first. This remains the compact, no-JavaScript form of the same demonstrating it — so if a page ships exactly one interaction, make it this one.

Use it when

  • The page makes the compile claim. It is section 3 of the mandatory composition.
  • You want the reader to check rather than believe.
  • You have real emitted files, with paths and hashes.

Don't use it when

  • You would fill it with hand-written code. That defeats the entire component.
  • You would show fewer than six tabs. Show the set; leave the unfilled ones empty and labelled.
  • You are tempted to fabricate a sha256. Never.

export function RenderOnce({ label, multiplier, visible, onTrace }) {
	const setupDone = useRef(null);
	if (setupDone.current === null) {
		setupDone.current = true;
		onTrace('setup', { runs: 1 });

							const nextCount = count + 1;
							setCount(nextCount);
							onTrace('change', { count: nextCount });
						}}

					</button>

// @generated by @frameless/solid; do not edit.
import { createSignal, untrack, Show } from 'solid-js';

export function RenderOnce(props) {
	untrack(() => props.onTrace('setup', { runs: 1 }));
	const [count, setCount] = createSignal(1);
	const prefix = untrack(() => `${props.label}:`);
	const derived = () => `${prefix}${count() * props.multiplier}`;
	return (
		<div data-s1-root="">
			<Show
				when={!props.visible}
				fallback={
					<section data-scenario="s1">
						<output data-value="derived">{derived()}</output>
						<button
							data-action="increment"
							onClick={() => {
								setCount(count() + 1);
								props.onTrace('change', { count: count() });
							}}
						>
							increment
						</button>
					</section>
				}
			>
				<p data-branch="hidden">hidden</p>
			</Show>
		</div>
	);
}

What the reader is supposed to notice

One source, one conditional branch, one derived value. The cheapest possible proof that the emitters are not doing lowest-common-denominator syntax translation: Solid reaches for <Show when= fallback=>, React and Qwik emit a ternary.

That difference is the product working. No lowest-common-denominator shape, no wrapper components — the React output uses React patterns and the Solid output uses Solid patterns, because the compiler works from meaning rather than from syntax.

Provenance

Motion and reduced motion

Panels swap on slide — cubic-bezier(0.65, 0, 0.35, 1) at 300ms, symmetric because a swap has no privileged direction. Under prefers-reduced-motion: reduce the translate is removed entirely and only the opacity moves, capped at 120ms.
