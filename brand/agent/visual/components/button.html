button

Three levels. The primary one is where lime does what lime is for — a fill with an ink label on it, at 12.43:1.

Use it when

  • primary for the one thing you want done. One per section.
  • secondary for the real alternative — "See the output" next to "Run the demo".
  • ghost for tertiary, in-context actions.

Don't use it when

  • The label on a lime fill is white (1.48:1) or cream (1.39:1).
  • You want three primaries in a row. Then none of them is primary.
  • You are reaching for box-shadow to make it look clickable.

Sizes

On the dark bed

The role tokens flip as a set, so the same three classes work without a per-surface variant. Note the secondary button's keyline becomes cream — it is still --ink, it is just that --ink means something different here.

Disabled — geometry, not opacity

An opacity-dimmed button reads as a loading skeleton. A dashed keyline with no fill reads as a thing that has not been printed yet, which is the vocabulary this brand already has for something that is not there.

As a sticker

For a hero CTA that should read as a collectible rather than as a control. Tilt it, and let it peel.

The two label colours that are always wrong

Shown once, at full size, because both look plausible in a design tool and neither is readable. Name them and an agent stops producing them.

1.48:1. Fails everything.

1.39:1. Fails everything.

12.43:1. The flagship pairing.

Focus

Tab through this page. The ring is two-tone by design — inner --ink, outer --accent — so on any surface one half clears 3:1 and no per-surface focus style is needed. Because these buttons already carry an --ink keyline at exactly --focus-width, focusing one shifts nothing.
