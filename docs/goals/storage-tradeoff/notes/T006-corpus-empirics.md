## Empirical corpus receipt

Scope: all 10 named local checkouts exist. Inspection was read-only; no files were written. “No consent” and “no sync” below mean no such branch/listener appeared in the inspected first-party implementation, not a legal conclusion.

### Frequency counts

- 9 of 10 repositories contain relevant first-party device-state code. `js-framework-benchmark` only contains incidental storage code inside bundled framework implementations.
- 6 active, independently authored theme-persistence families were observed: Qwik UI themes, Qwik Devtools, Qwik browser extension, Qwik Astro website, Design System Manager, and Frameless Goalbuddy boards.
- Those 6 families occupy 9 physical source copies: Qwik UI (1), Devtools (1), browser extension (1), Qwik Astro layouts (2), DSM (1), and byte-identical Frameless board applications (3).
- Two additional Qwik artifacts express the same pattern but were not counted as active: an unwired docs-site helper and a cookbook sample. Including them gives 8 authored theme-persistence variants.
- Fumadocs delegates theme persistence to `next-themes`; it is not counted as locally hand-rolled.

### Honest gaps

- Local code cannot establish adoption numbers, usage prevalence, production traffic, performance frequency, or user preference distributions.
- `next-themes` source is not installed in the Fumadocs checkout, so its internal key default, injected script, storage-event behavior, exception handling, and CSP behavior cannot be proven from this corpus.
- The Qwik docs theme helper has no discovered callsite; the corpus proves the implementation exists, not that the current docs build executes it.
- Static inspection cannot prove whether a flash is perceptible; DSM and Goalbuddy flash statements above are explicitly inferences from execution order.
- Absence of a consent check or storage listener is bounded to the inspected first-party source and grep terms; runtime wrappers or external dependencies could add behavior.
- Generated outputs, dependency trees, `.git`, POCs, and historical agent worktrees were excluded from implementation counts. Markless and `poc/**` remained read-only.
