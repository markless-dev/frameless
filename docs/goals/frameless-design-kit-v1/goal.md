# Goal: Frameless atomic brand kit — a brand world model agents can build from

## Original request

> I want you to make a design kit for frameless based on this article: *The HTML Brand:
> The Rise of Input-Based Outcomes* (Little Plains — Emmett Shine & Alex Leiphart).
> ... Lime green is the brand's primary color. `#cce007` is the primary color.
> [concept art image] is the concept art. I also want you to generate some systems for us
> using <https://utopia.fyi/>.

Supporting brief: `frameless-website-prompt.md` at repo root (sticker theme, Que Grotesque,
framework logos, Frameless Studio coming soon, interaction references).

## Interpreted outcome

A **Frameless atomic brand kit** in the shape the article describes — a zip-able,
self-contained folder where the brand is encoded as *instructions an agent can act on*,
not documentation a human reads and drifts from.

```text
frameless-brand-kit/
├── readme.md
├── magic_trick.md
├── human/          ← human-readable brand guidelines (HTML, not PDF — see note)
└── agent/
    ├── verbal/     positioning, audience, messaging, differentiation, concepts, voice
    └── visual/     colors_and_type.css, tokens/, fonts/, assets/, components/,
                    motion/, artifacts/
```

The test of the kit is not how it reads. It is whether a cold agent, given only the folder
and one sentence, produces something unmistakably Frameless.

## Input shape

`existing_plan` — the owner supplied a detailed reference article that specifies the exact
deliverable shape, plus three hard inputs (primary color, concept art, Utopia tooling) and
a prior brief. The article's folder structure is preserved as fact and adapted to Frameless,
not rediscovered.

## Goal oracle

Two signals, both required:

1. **Cold-agent one-shot.** A fresh subagent with **zero conversation context** is given
   only the kit path and a single prompt — *"generate me an HTML landing page based on the
   atomic design system and strategy"* — and its output is judged by Judge against the kit
   for: correct color tokens (`#cce007` used as the system specifies, not as decoration),
   Que Grotesque actually applied, Utopia fluid scales used for type and spacing, motion
   values traceable to `motion/`, real sticker/coastal aesthetic rather than generic, and
   copy that follows `voice.md` and `positioning.md` rather than generic dev-tool prose.
   The output must be recognizably Frameless to someone who has seen the concept art.
2. **Structural gate.** A deterministic check that the kit is internally sound: every
   token, font, and asset path referenced actually resolves; the CSS parses; the Utopia
   `clamp()` scales are mathematically correct and match their recorded config URLs;
   `/human` and `/agent` describe the same system without contradiction; no dead links.

A kit that passes (2) but fails (1) is a folder, not a system. A kit that passes (1) once
by luck but fails (2) will not survive the second prompt. Both hold, or the goal is not done.

## Constraints (non-negotiable)

- **`#cce007` is the primary.** It is the anchor, not a suggestion. The system must state
  where it is load-bearing and where it must not appear, and must carry accessible pairings
  — lime on white is a contrast trap and the kit has to say so with real ratios.
- **Que Grotesque is purchased and licensed.** Self-hosted WOFF2 subsets only. Never commit
  OTF/TTF/Variable source into the kit, never hotlink, never upload the font anywhere. The
  kit must carry a licensing note so a downstream agent does not redistribute it.
- **Utopia scales must be generated by driving <https://utopia.fyi/> in a real browser**,
  with the shareable config URLs stored in the kit so every scale stays re-tunable. Baked
  CSS with no config URL is a static artifact and fails owner intent.
- **The concept art is the visual north star** — coastal/lighthouse illustration, thick
  cream sticker die-cut with heavy black outline, lime display type, framework logos as
  collectible stickers. The kit's aesthetic direction derives from it.
- **HTML/CSS/SVG/MD/JSON/YAML only.** No flat raster where a structured format would carry
  the logic (the article's core argument). Raster is acceptable only for photographic
  texture and the source concept art.
- **Frameless Studio is not shipped.** Any mention is "coming soon" and must not imply
  availability.
- Kit is additive. Do not modify `packages/`, `demos/`, `poc/`, or the in-flight
  `website/` variant work except to *read*.

## Approach decisions (owner-selected during intake)

- **Independent of `frameless-website-v1`.** That board stays live and keeps building its
  variants on its own CSS. Two token systems will coexist for a while; reconciling them is
  a deliberate later decision, explicitly accepted, not an accident to be fixed mid-flight.
- **Full kit — verbal and visual.** The verbal half (positioning, audience, messaging,
  differentiation, concepts, voice) is authored, not stubbed. Every bold judgment call is
  flagged for the owner to accept or overrule rather than buried.
- **Utopia driven in a browser**, config URLs preserved in the kit.
- **Cold-agent one-shot is the primary proof**, backed by a structural gate.

## The verbal half — where the judgment calls live

This is the part the article says is actually valuable, and the part a downstream agent
cannot invent from a hex code. Frameless has real strategic territory to claim:

- the inversion thesis (write once, emit real framework-native code, not a runtime);
- compile-once/output-anywhere across React, Vue, Svelte, Solid, Angular, Qwik;
- activation-neutrality — the same source hydrates in React/Solid and *resumes* in Qwik;
- where it sits relative to Mitosis and to the frameworks it targets;
- who it is for: library authors and design-system teams who currently ship six packages.

The Scout phase reads the repo, `AGENTS.md`, and prior goal receipts to ground these in
what Frameless *actually does today* rather than aspiration. Positioning that overclaims
is worse than none — it will be faithfully amplified by every downstream generation.

## Likely misfire

The highest-probability failure is **a tidy folder of plausible files that no agent can
build a coherent page from.** The shape is easy to imitate; the coherence is not. Specific
guards:

- A `tokens/` folder that is a color list rather than a system with stated intent fails —
  tokens must say *when and why*, not just *what*.
- `voice.md` that says "friendly but technical" fails. Voice files must carry real
  do/don't pairs with Frameless-specific example copy an agent can pattern-match.
- Motion described in prose fails. It must be JSON parameters plus a rendered specimen you
  can feel.
- Utopia scales pasted as static `clamp()` with no config URL fails owner intent.
- A kit that only works because the generating model remembered this conversation fails —
  hence the *cold* agent with zero context.

Second misfire: spending the tranche on beautiful asset generation and never running the
one-shot test. The one-shot is run early against a partial kit, then again at the end.

## Non-goals

- Building the Frameless website or any landing page as the *deliverable*. Pages generated
  during this goal are **proof artifacts** for the oracle, not shipped product.
- Rewriting, reconciling, or blocking the `frameless-website-v1` variants.
- Shipping Frameless Studio or designing its UI beyond what the kit needs to reference.
- Buying fonts, domains, or hosting. Deploying anything.
- Logo redesign from scratch — the concept art defines the mark's treatment.
- Refactoring `packages/` or the demo apps.

## Note on `/human`

The article's `/human` folder holds traditional PDF brand guidelines. Frameless has none,
and there is no design team producing them. Rather than ship an empty folder or fake a PDF,
`/human` gets a **rendered HTML brand guideline** generated from the same token and verbal
files the agent half uses — one system, two presentations, guaranteed in parity because
they share a source. This is a deliberate adaptation of the article's shape and is flagged
here so it reads as a decision rather than an omission.

## What counts as enough for this tranche

A complete kit at `brand/` (path confirmed in T002) that:

- has the full folder shape with no placeholder files;
- carries a real verbal system grounded in what Frameless actually ships;
- carries Utopia-generated fluid type and space scales with live config URLs;
- carries `#cce007` as a documented system with accessible pairings and stated ratios;
- carries components, tokens, motion, and assets as structured HTML/CSS/SVG/JSON;
- includes `readme.md` (how to use it) and `magic_trick.md` (where the human walks back in);
- passes the structural gate;
- passes the cold-agent one-shot, judged against the concept art and the verbal system.
